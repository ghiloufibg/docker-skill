# Team review rules

`SKILL.md` step 6 points here. These checks come from what this team's
reviewers actually asked for in past merge requests. Each one was approved by
a person; none is generated on the fly. They apply to every project and
service, and use the same severity scale, evidence rule and report structure as
every other checklist.

Each check has a `T` number. A finding cites the check it breaks, for example
"Team rules — T7".

No team rules have been approved yet. Rules are added by running the review
memory pipeline (see `review-memory.md`) and pasting the accepted checks below
this line.
