# docker-skill

Experimental Claude Code skill: a Docker operations/investigation UI backed
by an MCP server, built to test the **MCP-UI** technique (MCP tool results
that render rich, interactive UI in the host and can push new prompts back
into the agent).

Nothing is implemented yet. See
[`docs/design/mcp-ui-docker-ops.md`](docs/design/mcp-ui-docker-ops.md) for
the architecture, communication protocol, tool/risk-tier catalog, security
model, and the staged plan for building and validating it.
